# QQQ 美股投研仪表盘优化路线图

> 更新日期：2026-08-03  
> 定位：个人研究用的 QQQ 定投与仓位辅助工具；不连接券商、不记录个人资产、不执行交易，也不构成投资建议。

## 目标

将仪表盘从“显示当前指标”逐步升级为可复核的决策闭环：

> 当前状态 → 触发原因 → 距离阈值 → 状态变化 → 本期行动 → 事后验证

现有五档状态、仓位范围与定投倍率仍是唯一正式决策输出。新增指标在获得用户明确授权且完成回测前，仅作展示或佐证，不得改写现有规则。

## 优先级总览

| 阶段 | 目标 | 解决的问题 | 是否影响正式决策 |
| --- | --- | --- | --- |
| P0 | 决策闭环 | “未触发”之外，离触发还有多远、市场在改善还是恶化、本期如何执行 | 否，解释现有规则 |
| P1 | 风险佐证 | 上涨是否广泛、波动是否异常、信用环境是否收紧 | 初期否 |
| P2 | 数据可靠性 | 恐贪、宏观日历不可用时如何稳健展示 | 否 |
| P3 | 策略验证 | 规则在不同环境下是否有效、是否过度拟合 | 不直接影响 |
| P4 | 个性化规划 | 将倍率转为具体的定投金额与现金计划 | 需用户另行授权 |

## P0：决策闭环（最高优先级）

### 1. 阈值距离与趋势矩阵

为每项规则显示当前值、触发值、剩余距离及短期方向，而不只显示“已触发 / 未触发”。

| 规则 | 当前值 | 触发条件 | 距离 | 近 5 日方向 |
| --- | ---: | ---: | ---: | --- |
| RSI(2) 超卖 | 75.88 | ≤ 15 | 60.88 | 下降 / 上升 / 平稳 |
| RSI(6) 超卖 | 49.41 | ≤ 30 | 19.41 | 下降 / 上升 / 平稳 |
| 回撤风险 | -7.8% | ≤ -12% | 4.2 个百分点 | 扩大 / 收窄 |
| VIX 风险 | 16.01 | ≥ 30 | 13.99 | 上升 / 下降 / 平稳 |
| 异常放量 | 1.26 倍 | ≥ 2 倍 | 0.74 倍 | 上升 / 下降 / 平稳 |

目的：区分“远离机会”“接近触发”“多项条件同步恶化”，并保持规则完全透明。

### 2. 状态历史时间轴

提供最近 90 天 / 180 天的状态变化记录：每次切换日期与原因、建议仓位和定投倍率、状态后 5 / 20 / 60 个交易日表现、状态持续时间与切换频率。

目的：回答当前状态是从“谨慎”修复而来，还是从“建设性”转弱而来；相同的中性状态可能对应不同背景。

### 3. 本期行动卡

顶部结论增加当前状态、建议仓位区间、常规定投倍率、额外加仓是否满足、下一组关键观察条件，以及数据完整度。后续可允许用户仅在浏览器本地设置“基础定投金额”，展示各倍率的金额示例；该设置不得上传、持久化到服务器或参与正式信号计算。

### 4. 情景推演

提供只读“如果……会怎样”面板，允许临时调整 QQQ 价格、RSI、VIX、回撤或成交量，展示该假设下的预计状态与原因。

必须标注“模拟结果，不是当前实时信号”，且不能覆盖实际 payload、规则配置或页面正式结论。

### 5. 低噪声提醒

提醒只应在有决策意义的变化时出现：五档状态切换、指标进入阈值附近、两项及以上风险条件同时触发、关键数据源持续失败，或 FOMC、CPI、非农等事件临近。不要对每次 15 分钟刷新都发提醒。

## P1：风险佐证层

新增指标的目标是补充与 RSI、回撤、VIX 不同的信息维度；初期只显示为“佐证”，不改变五档状态。

### 1. 市场宽度与集中度

建议关注纳斯达克 100 等权表现相对 QQQ 的强弱、上涨成分股占比、位于 50 日和 200 日均线上方的成分股比例，以及新高与新低家数。

纳斯达克 100 等权指数与纳斯达克 100 使用相同成分股、但采用等权方式，适合观察指数上涨是否由少数权重股主导。参考：[Nasdaq-100 Equal Weighted Index Methodology](https://indexes.nasdaq.com/docs/methodology_NDXE.pdf)。

解释示例：QQQ 创新高但等权表现持续走弱时，应标为“上涨集中度偏高”，而不是自动转为空头信号。

### 2. 波动率期限结构

在 VIX 之外，增加 VIX3M 及 VIX / VIX3M 比值，展示为“正常 / 紧张 / 倒挂”。VIX 代表约 30 天预期波动，VIX3M 代表约 3 个月预期波动；短期限明显高于长期限可作为短期压力的补充确认。参考：[Cboe VIX Methodology](https://cdn.cboe.com/api/global/us_indices/governance/Volatility_Index_methodology_VIXMO_only.pdf)。

### 3. 信用与金融条件

以低频风险背景方式展示高收益债信用利差、芝加哥联储 NFCI 和 10 年期与 2 年期美债收益率差。

NFCI 高于零通常表示金融条件较历史平均偏紧，低于零表示偏松。参考：[FRED NFCI](https://fred.stlouisfed.org/series/NFCI)。10 年－2 年期限利差可从 FRED 的日度序列获取。参考：[FRED T10Y2Y](https://fred.stlouisfed.org/series/T10Y2Y/)。

## P2：数据可靠性与宏观事件

当前 CNN Fear & Greed 与 BLS 网页抓取有已知可用性风险。优化方向：

- CPI、失业率等已公布数值优先改用 BLS 官方 API；
- FOMC 日期优先使用美联储官方会议日历；
- 每个数据项展示来源、最近成功时间、缓存状态与过期状态；
- 抓取失败时保留最近有效快照并明确标记过期；
- 任一辅助来源失败时，核心 QQQ 信号继续运行，且不得伪造实时数据。

BLS API v1 可无需注册使用，适合本项目的基础公开数据查询。参考：[BLS Developers](https://www.bls.gov/developers/home.htm)。FOMC 会议与纪要日期可参考：[Federal Reserve FOMC Calendars](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm)。

## P3：策略验证与研究记录

回测应从“累计收益摘要”扩展为可审视规则质量的研究工具：

- 买入并持有、固定 40% 配置、现有规则的并列对比；
- 年化收益、波动率、最大回撤、恢复时间、换手率；
- 每个状态出现次数、平均持续时间、状态后 5 / 20 / 60 日表现；
- 各规则触发后的命中率与最大不利变动；
- 滚动窗口、样本外测试和阈值敏感性测试；
- 手续费、滑点、现金闲置等现实摩擦的影响。

同时加入“决策日志”：每次状态切换记录当时的输入、规则结论和后续表现，用于复盘，而不是事后解释。避免仅根据历史最优结果调整阈值；这会产生过度拟合风险。

## P4：需单独确认的个性化能力

以下能力更贴近个人资金管理，但超出当前产品边界，必须另行设计并征得明确授权：基础定投金额、现金储备周期和目标仓位的本地规划；持仓、成本、税务批次或券商数据导入；自动化通知渠道；估值锚点、新闻或情绪摘要。

其中持仓与券商接入涉及隐私、安全和决策边界，不应作为当前阶段的默认功能。

## 不建议优先做的事项

- 为了“更多指标”直接加入 MACD、布林带等高度相关指标；
- 将恐贪、新闻或单个板块行情直接写入仓位规则；
- 接入自动交易或保存券商凭据；
- 未完成历史验证就更改 RSI、回撤、VIX 等现有阈值；
- 对每次刷新发送通知。

## 推荐实施顺序

1. 阈值距离与趋势矩阵；
2. 状态历史时间轴；
3. 本期行动卡；
4. 情景推演；
5. 市场宽度与波动率期限结构；
6. BLS / FOMC 与数据状态可靠性改造；
7. 扩展回测、信号归因与决策日志；
8. 状态变化提醒；
9. 仅在另行确认后开展个性化资金规划。

## 验收原则

- 每项新增展示都应能回答一个明确的决策问题；
- 新数据必须标明来源、时间与可用性；
- 新指标默认不改变五档正式决策；
- 涉及规则、阈值、仓位范围或定投倍率的改动，必须先获用户明确授权并完成回测；
- 桌面和手机端都能读取核心结论，不能依赖悬停；
- 数据不足时优雅降级，不能伪造实时性。
