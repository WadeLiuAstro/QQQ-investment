# QQQ 美股投研仪表盘路线图（体系驱动版）

> 更新日期：2026-08-04
> 唯一设计依据：[`docs/investment-system.md`](investment-system.md)（投资交易体系 v1.0）。平台规则与体系冲突时，以体系为准。
> 定位：个人研究用的 QQQ 定投与仓位辅助工具；不连接券商、不记录个人资产、不执行交易，也不构成投资建议。

## 核心原则

- **体系先行**：一切新功能必须能对应到体系文档的某一节；对不上号的"好想法"不做。
- **分层不替换**：现有五档状态与定投倍率仍是正式输出，新体系能力以"趋势层、归因层、参考层"叠加，不推翻既有输出。
- **日频决策**：正式信号一律基于日频收盘价；盘中数据只服务熔断级预警。
- **先回测再调参**：涉及阈值与规则的改动，必须先完成历史回测并记录理由。

### S2 归因拍板机制与决策日志（体系的"闸门"） ✅ 已完成（2026-08-04）

对应体系 §5、§9.1。

交付记录：
- `app/services/attribution.py`：大跌检测（单日 ≤ -2% 或回撤跨新 5% 档）+ 证据集组装（VIX 跳升、宽度 RS、事件日历、回撤深度/速度）+ 闸门状态机（open/half/frozen，超时未拍板=减半，48h 倒计时）

## 验收原则

- 每项新增展示都应能回答一个明确的决策问题，且能指向体系文档的具体章节；
- 新数据必须标明来源、时间与可用性；
- 正式输出（五档状态、定投倍率）不被新层改写，除非体系文档明确修订；
- 涉及规则、阈值、仓位范围或定投倍率的改动，必须先获用户明确授权并完成回测；
- 桌面和手机端都能读取核心结论，不能依赖悬停；
- 数据不足时优雅降级，不能伪造实时性；
- 盘中数据永不产生正式信号。
