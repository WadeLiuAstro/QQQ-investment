# 纳斯达克综合指数 K 线卡片设计

## 目标与范围

在 QQQ 信号带下方增加全宽的纳斯达克综合指数（`^IXIC`）日 K 卡片。该卡片只用于观察整体市场走势，不参与 QQQ 五级仓位、定投倍率或回测决策。

## 数据与降级

- 数据源：沿用 yfinance/Yahoo Finance，拉取 `^IXIC` 近一年日线 OHLCV。
- 刷新：沿用现有本地 15 分钟调度与 GitHub Actions 静态刷新。
- 载荷：在 `market.ixic` 输出当前点位、上一收盘、日内涨跌点数/百分比，以及最长一年的 OHLC 数组。
- 来源状态：使用独立 `yahoo_ixic` 状态；失败时保留该卡片的上次同标的有效快照并标记过期，首次失败则显示“数据暂不可用”。不得影响 QQQ 信号。

## 图表与交互

- 图表：使用固定版本 CDN 的 Lightweight Charts，在静态页面渲染可交互蜡烛图。
- 默认范围：近 3 个月；可切换 1 个月、3 个月、6 个月、1 年。前端在已导出的最长一年数据中本地筛选，不发起新的市场数据请求。
- 颜色：上涨 `#3DDC97`，下跌 `#F0656B`；不引入新的涨跌配色。
- 详情：十字线悬停/触摸时显示交易日和 OHLC；无有效十字线时显示最新日线 OHLC。
- 移动端：图表容器监听尺寸变化并重绘；维持默认 3 个月数据范围，允许图表自然压缩或横向手势查看，不伪造缩短周期。

## 布局

1. 现有信号带。
2. 新增 `nasdaq-composite` 全宽卡片：标题、指数点位、涨跌点数/百分比、周期按钮、K 线与 OHLC 信息。
3. 现有 QQQ/宏观双卡及其余内容保持原顺序。

## 测试

- Yahoo 多列 OHLC 返回映射为日线对象的测试。
- `^IXIC` 市场载荷包含 OHLC 序列、当前点位和涨跌信息的测试。
- 数据不可用时该卡片独立降级的测试。
- 静态页面包含卡片、周期选择器和图表容器的契约测试。
- 前端周期筛选与 OHLC 提示函数的确定性测试。

## 不在范围内

- 不将 `^IXIC` 纳入 QQQ 规则、回测或仓位建议。
- 不新增付费行情源、实时逐笔行情、分钟 K 线或新闻解读。
