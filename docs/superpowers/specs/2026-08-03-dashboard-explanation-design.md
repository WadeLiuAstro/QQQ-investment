# 仪表盘信息密度与信号解释设计

## 目标
提升板块、宏观指标与信号拆解的可读性，不修改 QQQ 仓位与定投规则。

## 界面
- 板块佐证使用两列横向卡片；每张卡片将中文名称、ETF 代码与价格放在同一行。移动端降为单列，避免中文换行。
- VIX 标签显示为“VIX（恐慌指数）”。
- 信号拆解展示当前规则计算值与阈值：加仓机会、建设性加仓、减仓风险与成交量/恐贪数据状态。

## 规则边界
- 仅在浏览器端将已有行情与指标格式化为解释文本。
- 不改变 `app/services/decision.py` 的状态判断、阈值、仓位范围或定投倍率。
- 恐贪数据不可用时明确说明 CNN 免费接口抓取失败，且该数据未纳入判断。

## 验证
- 静态测试验证 VIX 中文标签、横向板块标记和规则解释函数。
- 现有决策测试继续保证规则未被修改。
