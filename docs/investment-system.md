# 投资交易体系 v1.0

> 生成日期：2026-08-04
> 来源：grilling session 十四问逐条拍板
> 地位：本平台一切功能设计与改造的唯一依据；平台规则与本体系冲突时，以本体系为准。

## 0. 定位与边界

- **资金用途**：中长期投资增强（核心持有 + 主动加减仓增强收益），非养老死钱，也非短线交易。
- **标的**：QQQ（纳斯达克 100 ETF）为主。
- **边界**：不接券商、不自动下单、不记录个人资产明细；平台输出建议，人执行。
- **纪律红线**：盘中噪音不产生决策；一切正式信号基于日频收盘价。

## 1. 资金结构

| 项 | 约定 |
| --- | --- |
| 资金池 | 单池，不切分核心/战术 |
| 仓位浮动区间 | 40%（下限常驻）— 90%（封顶） |
| 卖出后资金去向 | 现金/货币基金，作为待命弹药，不设上限 |
| 已知风险 | 现金无上限 → 极端情况可能长期低仓位踏空；靠"进场快于出场"的不对称设计防守 |

## 2. 决策框架：多因子 + 仲裁规则

- **主因子**：技术面（定方向：买 / 卖 / 不动）
- **辅因子**：估值、宏观、流动性（只调力度，不能推翻方向）
- **仲裁模式**：主因子一票定方向，辅因子在方向内调节仓位深浅（±10%）
- **冲突示例**：技术面破位 + 估值极便宜 → 方向仍是防守，但只减到 50% 而非 40%

## 3. 趋势判定（方向层）

| 规则 | 定义 |
| --- | --- |
| 多头环境 | QQQ 收盘价 ≥ MA200，收复即算（进场积极） |
| 空头环境 | 收盘价连续 3 日低于 MA200 且低于幅度 ≥ 1%（出场要确认，防锯齿） |
| 快速熔断 | 单月回撤 ≥ 8% 时，无论 MA200 状态，立即降仓至 50% 并触发归因拍板 |

设计依据：慢指标假信号少；不对称（慢出快进）因为定投增强体系中踏空的复利损失 > 短期被套。

## 4. 买入触发（多头环境内）

1. **网格主干**：距 52 周高点每回撤 5%，仓位 +5%（从基准 70% 起，90% 封顶）
2. **超卖加速**：RSI(2) ≤ 15 时允许一次性加速买入，不等网格步进
3. **归因闸门**：所有买入必须通过第 5 节的大跌归因检查

## 5. 大跌归因分析（机器举证、人拍板、超时减半）

大跌（单日 ≥ -2% 或回撤进入新台阶）时平台自动生成证据集：

- VIX 水平与跳升幅度（恐慌 vs 慢性失血）
- 市场宽度（QQQE/QQQ 相对强弱）
- 信用利差 / 利率变化（金融条件）
- 事件日历（FOMC / CPI / 财报导火索）
- 回撤性质：速度（5 天 -10% vs 60 天 -10%）

用户拍板三选一（须附一句话理由，写入决策日志）：

| 分类 | 系统行为 |
| --- | --- |
| 流动性恐慌 | 正常执行加仓 |
| 结构性风险 | 冻结加仓，仓位只出不进或维持下限 |
| 待观察 | 减半执行，48 小时后复核 |

超时未拍板 = 减半执行（防止恐慌时不敢操作）。

### 5.1 结构性风险量化评分（0–100，自动预警）

| 维度 | 量化特征 | 满分 |
| --- | --- | --- |
| 回撤深度 | 距 52 周高点回撤 ≥ 15% 起计，每深 5% 加一分 | 30 |
| 回撤速度 | 回撤主要发生在 > 40 个交易日（慢性失血） | 20 |
| 宽度恶化 | MA200 上方成分股占比 < 30% 且 QQQE/QQQ 相对强弱 20 日为负 | 25 |
| 波动率体制 | VIX 连续 10 日 > 25，或 VIX/VIX3M > 1.2（期限倒挂） | 25 |

判读：≥ 70 分 → 标红疑似结构性，冻结加仓等拍板；40–69 → 加仓减半；< 40 → 视为流动性恐慌正常执行。
宏观因子（失业率、收益率曲线倒挂时长等）作辅助交叉验证，不纳入主评分。

## 6. 卖出触发

1. **机械再平衡**：仓位因上涨被动超过 90% → 减回 80%
2. **泡沫预警**：结构性评分反向特征（宽度极度收窄 + 估值极贵 + VIX 长期 < 12）≥ 70 分 → 主动降至 60%
3. **空头环境**：MA200 确认跌破 → 降至下限 40% 常驻
4. 估值过热、技术顶部信号（RSI 背离、放量滞涨）仅作拍板证据，不作自动触发

## 7. 仓位映射总表（参考层）

| 步骤 | 规则 |
| --- | --- |
| 趋势定基准 | 多头 70%；空头 40%；熔断 50% 待归因 |
| 多头内网格 | 每回撤 5% 仓位 +5%，90% 封顶 |
| 结构评分闸门 | 40–69 分加仓减半；≥ 70 分冻结加仓 |
| 辅因子调节 | 估值分位 > 90% → -10%；< 20% → +10%；宏观收紧再 -5% |
| 卖出侧 | 超 90% 减回 80%；泡沫评分 ≥ 70 降至 60% |

风险参照：90% 仓位遭遇 2022 年级别下跌 ≈ 账户回撤 -30%，为当前体系的最大回撤承受。

## 8. 执行框架与决策节奏

- **正式输出**：维持现有定投倍率框架（当前无大额新增资金，目标仓位制暂无执行对象）
- **映射表角色**：市场认识 / 参考层，帮助理解当前市场状态，不直接生成交易指令
- **决策节奏**：日频为主（收盘后决策）+ 盘中仅熔断级事件预警（单日 -3% 以上、VIX 暴涨）
- **盘中规则**：15 分钟高频数据只服务于预警守护进程，不产生正式信号

## 9. 复盘与检验

1. **决策日志（自动）**：信号触发、归因拍板、实际执行（含未执行）全部落库
2. **每月复盘（手动，约 10 分钟）**：
   - 本月执行的信号，事后看对 / 错 / 运气？
   - 有无违反纪律的操作（该买没买、该卖没卖、拍脑袋操作）？
   - 规则需要修订吗？（修订必须记录理由，防止按结果调参）
3. **年度对标（自动计算）**：实际收益 vs 三条基准——买入持有 QQQ、固定 65% 仓位持有、体系"理论完美执行"收益
   - 跑输"理论完美执行"很多 → 问题在执行
   - 体系本身跑输买入持有 → 才质疑规则
4. **历史回测（后期）**：对本策略做历史回测验证收益率（排期在平台改造之后）

## 10. 与现有平台的差异清单（改造依据）

| 现有平台 | 体系要求 | 差异 |
| --- | --- | --- |
| 五档状态由 RSI/回撤/VIX 阈值决定 | 技术面定方向 + 结构评分闸门 | 需引入 MA200 趋势层与结构评分 |
| 无归因机制 | 机器举证 + 人拍板 + 超时减半 | 全新功能 |
| 15 分钟全量刷新 | 日频决策 + 盘中轻量预警 | 刷新架构重构 |
| 定投倍率为唯一正式输出 | 保持，映射表作参考层 | 输出结构扩展而非替换 |
| 无对标基准 | 三条基准线自动计算 | 新增年度对标 |
